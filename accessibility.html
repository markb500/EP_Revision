Accessibility statement for the Electrical Principles Revision Aid

This accessibility statement applies to the Electrical Principles Revision Aid web application used to support revision for the electrical principles element of the RAF Aerospace Engineering Technician course.

This website is run by [name of public body / unit — complete before publishing]. We want as many people as possible to be able to use this website.

How you should be able to use this website

For example, that means you should be able to:

  • change colours, contrast levels and fonts using browser or system settings
  • zoom in up to 200% without the text spilling off the screen
  • navigate most of the website using only a keyboard
  • navigate most of the website using a screen reader (including recent versions of JAWS, NVDA and VoiceOver)

We’ve also made the website text as simple as possible to understand, noting that the content is technical electrical principles aligned to the course.

AbilityNet has advice on making your device easier to use if you have a disability.

Technical information about this website’s accessibility

[name of public body — complete before publishing] is committed to making its website accessible, in accordance with the Public Sector Bodies (Websites and Mobile Applications) (No. 2) Accessibility Regulations 2018.

Compliance status

This website is partially compliant with the Web Content Accessibility Guidelines version 2.2 AA standard, due to the non-compliances listed below.

Non-accessible content

Non-compliance with the accessibility regulations

  • Card flip animation is a visual presentation of reveal/hide. Name, role and state are exposed (button, pressed, labels including the definition when shown), but the 3D flip itself may not map one-to-one in every assistive technology (WCAG 1.3.1, 4.1.2).
  • Mathematical notation via MathJax may be announced unclearly by some assistive technologies (WCAG 1.1.1, 1.3.1).
  • Circuit symbol images have short text alternatives; complex multi-part diagrams (for example bridge rectifier) still rely partly on adjacent text for the full answer (WCAG 1.1.1).

Content not within the scope of the accessibility regulations

  • Third-party libraries loaded from a CDN (for example MathJax) are not fully under our control.

What we’re doing to improve accessibility

  • Visible keyboard focus indicators and a skip link
  • Cards implemented as buttons with keyboard support
  • Live status updates; load errors announced
  • Hidden card faces marked for assistive technologies
  • Text alternatives on circuit and waveform images in definitions
  • Improved colour contrast on definition faces
  • Respect for “reduce motion” system settings where supported

Preparation of this accessibility statement

This website was tested against WCAG 2.2 AA using a combination of:

  • manual keyboard-only checks of card navigation, flip, and Next set

  • review of structure, labels, focus, contrast, image alternatives, and motion preferences

Testing was carried out by the application maintainer. A full independent audit has not been claimed in this statement—update this section if a formal audit is completed.
